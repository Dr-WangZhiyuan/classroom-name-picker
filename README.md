# Classroom Name Picker

A retro slot machine-style random name picker for classroom use.

**Live site:** https://dr-wangzhiyuan.github.io/classroom-name-picker/

Student names are stored in the browser's localStorage only and are never sent to any server or included in this repository.

---

Developed by Dr. Wang Zhiyuan at Singapore University of Social Sciences (SUSS). During his childhood summers, he spent countless carefree hours playing *Snow Bros.* and other classic NES games (on 红白机/小霸王). Those are fond memories.
